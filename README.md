# mugen-hogwarts-releases

Releases públicas do **launcher** do Hogwarts. Este repositório tem só binários, publicados pelas [GitHub Releases](https://github.com/2hdsc/mugen-hogwarts-releases/releases). Não há código-fonte aqui.

- O launcher (e, no cliente leve, o motor e o pack base) é o que sai neste repo, para o jogador baixar e para o próprio launcher checar se há versão nova.
- Os packs de personagens e cenários, e o manifest, ficam no **Cloudflare R2** — não neste repositório (sprites de terceiros não vão para um repo público).
- O código-fonte do jogo e do launcher é privado, em [2hdsc/mugen-hogwarts](https://github.com/2hdsc/mugen-hogwarts).

Ainda não há uma Release publicada.
